Files in `_drafts/` are **not published**. They're handy for work in progress.

To preview drafts locally, run `bundle exec jekyll serve --drafts`.

When ready, move this file to `_posts/` and rename it with a date prefix, e.g.
`_posts/2026-07-01-my-post.md`.
