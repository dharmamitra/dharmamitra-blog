This is the official blog of the **Dharmamitra Project** — research news,
software releases, and updates on our work building AI tools for the study of
Buddhist and classical Asian languages (Sanskrit, Tibetan, Chinese, Pāli, and
more).

For the tools themselves — translation, search, and OCR — visit
[dharmamitra.org]({{ site.main_site }}).

## Contributing a post

Posts are plain Markdown files. See the project
[README](https://github.com/dharmamitra/dharmamitra-blog#readme) for how to add
one — drop a file in `_posts/`, push to `main`, and it publishes automatically.
